# Hanon, The Virtuoso Pianist, Part I, Nos. 1–20

LilyPond sources (`hanonNN.ily`) from the Mutopia Project edition, typeset by Steve Taylor and Javier
Ruiz-Alma after the Schirmer 1900 edition, licensed CC BY-SA 4.0
(https://github.com/MutopiaProject/MutopiaProject, `ftp/HanonCL/virtuoso-pianist-pt1`). Unchanged.

`pmfinger/hanon_score.py` reads them to label the 上音 Hanon takes with the printed fingering
(see that file for the rules). Self-test: `python3 -B scripts/selftest_hanon.py`.
